# Languages

The plugin follows the Obsidian app language (`getLanguage()`). Below are the languages Obsidian offers,
from [obsidianmd/obsidian-translations](https://github.com/obsidianmd/obsidian-translations#existing-languages)
(checked 2026-11-02). File name = lower-cased code: `zh-TW` → `zh-tw.ts`, `pt-BR` → `pt-br.ts`.

`en` is the source (`en.ts`), `ru` is maintained by the authors. `en-GB` uses English.
"Obsidian" shows how complete Obsidian's own translation is.
